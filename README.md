# Austral Group SAC - Portal de Servicio Técnico

Portal interactivo para gestión de personal técnico, cronograma y costeo.

## Características

- 👥 **Personal**: Ver, agregar, editar técnicos
- 📅 **Cronograma**: Programación de 2 semanas
- 💰 **Costeo**: Cálculo de horas y costos
- 📊 **Reportes**: Informes varios

## Tech Stack

- HTML/CSS/JS (Vanilla)
- Google Sheets API (datos)
- Chart.js (gráficos)

## Deployment

1. Ve a GitHub: https://github.com
2. Crea un nuevo repo: `austral-group-portal`
3. Sube este código
4. Activa GitHub Pages en Settings > Pages
